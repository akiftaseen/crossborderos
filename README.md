# CrossBorderOS

CrossBorderOS is an AI-native operations workspace for planning and governing a cross-border market expansion. This build focuses on a smart-hardware launch from Hong Kong / Greater Bay Area into Malaysia.

## Included in this MVP

- Readiness overview with category progress, blockers, evidence health, and project pulse
- Requirements register with risk filters, source provenance, and verification states
- Evidence/document workspace with upload and gap-review flows
- Launch timeline with gate ownership and human-verification checkpoints
- Professional review queue for legal, customs, tax, and certification sign-off
- Change monitor with version history and impacted requirements
- Source library with captured evidence records

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The interface uses illustrative sample data and is not legal, customs, certification, or market-entry clearance advice.
